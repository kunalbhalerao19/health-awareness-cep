# HealthFirst CEP – Health Intervention & Awareness Programs

A clean, responsive multi-page website built for the **Community Engagement Project (CEP)** on the theme of **Health Intervention and Awareness Programs**.

## 🌐 Live Demo
Deploy this site with GitHub Pages (see instructions below).

## 📋 Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero, about, focus areas, impact stats, testimonials |
| Programs | `programs.html` | 6 detailed health intervention programs |
| Awareness | `awareness.html` | Campaigns, health calendar, health tips |
| Resources | `resources.html` | Downloads, videos, external links, health calculators |
| Contact | `contact.html` | Contact form, FAQ accordion, helplines |

## 🏥 Health Focus Areas Covered
- ❤️ Cardiovascular Health
- 🧠 Mental Health
- 🩸 Diabetes Management
- 👶 Maternal & Child Health
- 🫁 Respiratory Health
- 🦠 Infectious Disease Control

## ✨ Features
- **Fully responsive** – mobile, tablet & desktop
- **Sticky navigation** with hamburger menu for mobile
- **Animated counters** for impact statistics
- **Scroll reveal** animations
- **Interactive health calculators** (BMI & Heart Rate Zone)
- **Contact form** with success state
- **FAQ accordion** on contact page
- **Health calendar** for awareness days
- Clean minimal design with blue/teal color scheme
- Built with pure HTML, CSS, and Vanilla JS — no frameworks required

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/health-awareness-cep.git

# Open in browser (no build step needed)
open index.html
```

## 🌍 Deploy on GitHub Pages
1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Under **Source**, select `main` branch → `/ (root)`
4. Click **Save** — your site will be live at `https://YOUR_USERNAME.github.io/health-awareness-cep`
